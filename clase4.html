3.12 Caracteres especiales

Como ya se aprendió en las clases anteriores, los archivos HTML son de texto ASCII y no deben contener nada de formato; los únicos caracteres que deben ir son los que se imprimen directamente del teclado. Los caracteres de los archivos HTML deben pertenecer al conjunto estándar de caracteres ASCII (de 7 bits), y no pueden ser ninguno de los caracteres del ASCII "extendido" (de 8 bits).

Para solucionar estos problemas, HTML define una serie especial de códigos, llamados entidades de carácter, que pueden usarse para representar los caracteres que se quiera emplear.

Entidades de carácter para caracteres especiales

Las entidades de carácter pueden ser de dos formas: entidades nombradas y entidades numeradas.

Las entidades nombradas empiezan con el signo ampersand (&) y terminan en punto y coma (;). En medio se encuentra el nombre del carácter. Los nombres distinguen entre mayúsculas y minúsculas, así que tenga cuidado de escribirlos exactamente.

Ejemplos: " ("), « («), © (©).

Las entidades numeradas también empiezan con ampersand y terminan con punto y coma, pero en lugar de nombre llevan el signo de número (#) y un número. Ese número corresponde al conjunto de ISO-Latin-1.

Ejemplos: ‚ (‚), õ (õ).

En los archivos HTML, las entidades nombradas o numeradas se colocan en el lugar del carácter que representan. Así, para poner la palabra francés en el archivo HTML, se escribirá: francés o bien francés

Entidades de carácter para caracteres reservados

Existen unos cuantos caracteres que tienen un significado especial en el propio HTML. Para estas excepciones también se deben usar las entidades de carácter. Por ejemplo, si se quiere poner una línea de código como la siguiente:

if x < 0 do print i

El problema es con el signo menor que (<) porque para HTML significa “el inicio de una etiqueta” y también con el signo mayor que (>) que significa “el final de la etiqueta”. La escritura correcta en HTML de la línea de código anterior, sería como sigue:

<p><code>if x &lt; 0 do print i</code></p>

3.13 Formateo del <BODY> - Atributos

En el “cuerpo” del documento <BODY>, va todo lo que queramos mostrar en nuestra página web. Esta etiqueta tiene atributos con los que se pueden personalizar según el aspecto que se desee:

  • Bgcolor (Color de fondo): Define el color de fondo para nuestra página.
    Ejemplo por nombre: <body bgcolor="red"></body>
    Ejemplo por hexadecimal: <body bgcolor="#FF0000"></body>
  • Text (Color de texto): Se usa para predefinir el color del texto de nuestra web.
    Ejemplo: <body text="#000000"></body>
  • Link, alink y vlink (Color de enlaces): link para el enlace inactivo, alink para el enlace activo (al hacer clic) y vlink para el enlace ya visitado.
    Ejemplo: <body link="#FF0000" alink="#FF0000" vlink="#0000FF"></body>
  • Background (Imagen de fondo): Se usa para que tu página tenga una imagen de fondo. Si la imagen no es suficientemente grande, se repetirá en mosaico.
    Ejemplo: <body background="imagen.jpg"></body>
  • bgproperties="fixed" (Imagen de fondo fija): Se añade para indicar si la imagen de fondo es fija y no se desplaza al mover el texto.
    Ejemplo: <body background="back.gif" bgproperties="fixed"></body>
  • Márgenes (topmargin, bottommargin, leftmargin, rightmargin): Define los márgenes en píxeles.
    Ejemplo: <body leftmargin="10" topmargin="10" rightmargin="10" bottommargin="10"></body>

3.14 Tamaño, color y tipos de fuentes

La etiqueta <FONT> </FONT> se usa para controlar las características de una cadena de caracteres específica:

  • Tipo de letra: <font face="Times New Roman">fuente</font>
  • Tamaño: <font size="5">Este es el tamaño 5</font>
  • Color: <font color="#FF0000">texto rojo</font>
